# PSG Team Aurora - Mars Rover Website

Official website for **PSG Team Aurora**, the Mars Rover student design team from PSG Institute of Technology and Applied Research (PSG iTech), Coimbatore.

Designed and developed with Next.js 16, React 19, Three.js, GSAP ScrollTrigger, and Lenis smooth scrolling.

---

## 🚀 Features

- **Interactive 3D Rover Experience**: Real-time 3D Mars Rover model rendered with Three.js (`@react-three/fiber` & `@react-three/drei`) with dynamic scroll animations and metallic materials.
- **Cinematic Scroll Animations**: Smooth scroll-linked camera and section transitions powered by GSAP ScrollTrigger and Lenis smooth scrolling.
- **Subsystem Breakdowns**: Detailed showcase of Mechanical, Autonomous, Science, and Electronics subsystems.
- **Team & Faculty Roster**: Comprehensive member profiles with roles and subsystem specializations.
- **Competition & Rover Specs**: Complete specifications and competition milestones for University Rover Challenge (URC) / Indian Rover Challenge (IRC).

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/), [@react-three/fiber](https://r3f.docs.pmnd.rs/), [@react-three/drei](https://github.com/pmndrs/drei)
- **Animations**: [GSAP](https://gsap.com/) & ScrollTrigger
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏁 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Nermal-M/Aurora.git

# Navigate to directory
cd Aurora

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm start
```
